
# 🖨️ Vendo Print Portal – Quick Guide

1. **Upload File**  
   - Click **“Upload a Photo or File”**.  
   - Supported: Images (JPG, PNG), Text (.txt), PDF.

2. **Enter Access Code**  
   - Type the code given by the admin.  
   - Click **“Validate Code”**.  
   - ✅ Accepted → proceed.  
   - ❌ Invalid → ask admin for a new code.

3. **Choose Page Size**  
   - Select **A4**, **Letter**, or **Long**.

4. **Select Print Mode**  
   - **Colored** → prints in full color.  
   - **Black & White Text** → for text files.  
   - **Black & White Image** → for images in grayscale.  
   - **ID Photo Set** → generates 2×2 and 1×1 photos on A4.

5. **Preview & Print**  
   - A preview will appear.  
   - Click **Print** to finish.

---

⚠️ **Notes for Customers**  
- Each code works **once only**.  
- You must validate your code before printing.  
- The portal prints **only the uploaded file** (no extra text).  
- For ID photos, upload a clear portrait image.
